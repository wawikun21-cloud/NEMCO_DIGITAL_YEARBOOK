# QR Code URL Fix Plan

## Problem
QR codes generate URLs like `http://localhost:5173/0026281` but should be `http://localhost:5173/u/0026281` to match the route pattern `/(u|profile)/identifier` expected by `PublicProfilePage`.

## Root Cause
Two issues found:

1. **`api/index.js` line 371**: `buildQrPayload(existing)` is called WITHOUT the `baseUrl` parameter (unlike server controller which passes `req.get("origin")`)
   - **THIS IS THE CRITICAL BUG - MUST BE FIXED**
   - Without the origin, the function falls back to `PUBLIC_PROFILE_BASE_URL` which defaults to `https://yourapp.com/u`

2. **Missing `PUBLIC_PROFILE_BASE_URL` in environment**
   - Falls back to default `https://yourapp.com/u` when not set
   - Need to configure for local development and Vercel deployment

## Fix Steps - MUST BE DONE

| Step | File | Change | Criticality |
|------|------|--------|-------------|
| 1 | `api/index.js` (line 371) | Change `buildQrPayload(existing)` → `buildQrPayload(existing, req.get("origin"))` | **CRITICAL** |
| 2 | `server/.env` | Add `PUBLIC_PROFILE_BASE_URL=http://localhost:5173/u` | Recommended |
| 3 | Vercel Dashboard | Add env var `PUBLIC_PROFILE_BASE_URL=https://nemco-digital-yearbook.vercel.app/u` | Required for production |

## Expected Result
- Local: `http://localhost:5173/u/0026281`
- Production: `https://nemco-digital-yearbook.vercel.app/u/0026281`

## Validation
- Restart the server after changes
- Generate a new QR code
- QR content should include `/u/` path segment
- Access the URL to confirm it displays the public profile
